Put your gym photos in this folder.

- hero.jpg  -> home page banner. Then add this line inside the <section class="hero"> tag in index.html:
               style="--hero-img: url('images/hero.jpg')"
- Gallery   -> in gallery.html replace the icon inside a <button class="g-item"> with
               <img src="images/your-photo.jpg" alt="Describe the photo">
- Coaches   -> in coaches.html replace the initials inside <div class="avatar"> with
               <img src="images/coach-name.jpg" alt="Coach name">
- "Visual" panels on Home/About -> replace the icon inside <div class="visual"> with an <img>.

Tip: keep photos under ~300 KB each (resize to ~1600px wide) so the site loads fast on mobile data.
